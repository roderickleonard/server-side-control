Install or upgrade

Install MySQL or MariaDB from the host package repository, or upgrade the currently installed package to the latest available version.

Persistent server settings

These values are written to a dedicated panel-managed MySQL config file so they survive reboot and package updates.

After saving, restart MySQL from the panel to apply the persistent changes. Bind address and slow query settings are included here too.

Service control

Start, stop, or restart the MySQL service without leaving the panel.

Open database provisioning Open MySQL logs

Schema creation, password rotation, restore, and per-database inspection stay available on the Databases screen.

Admin SQL

This runs with the saved MySQL admin defaults file. Use it for service-level checks, grants, schema operations, diagnostics, and emergency SQL.

Operational notes

  • Current connection count is live usage, while max connections is the configured upper bound.
  • Peak used connections helps you judge whether the current limit is too low or overly large.
  • Saving settings updates the panel-managed config file only; restart the service to apply them persistently.
  • Bind address controls where MySQL listens, and slow query settings help you diagnose heavy statements.
  • Admin SQL executes immediately and is audited. Review destructive statements carefully before running them.
