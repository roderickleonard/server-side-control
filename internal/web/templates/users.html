Validation rules

  • Usernames must begin with a lowercase letter or underscore.
  • Only lowercase letters, numbers, underscores, and hyphens are accepted.
  • New users are created as regular login users with `/bin/bash`.
  • If you want to use `sudo` inside the terminal, give the user a password and enable sudo access.
