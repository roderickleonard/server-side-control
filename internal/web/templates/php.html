    Current behavior

    • The panel uses the stored Nginx config path for the managed site.
    • The config is edited only when a PHP-FPM socket entry exists.
    • Version installs use the current apt sources available on the server.
    • Extension installs try the matching `phpX.Y-extension` package first, then enable the module for CLI and FPM.
    • Only versions detected from the host are shown in the dropdown.
